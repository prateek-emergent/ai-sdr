Giulia, where we started

The preview pod as we found it: a solid call skeleton in one language, with nothing left behind a call except a timing report.

Figure 1 · system

Where a call went

A browser call: the page asks the web backend for a room, LiveKit sends the voice worker in, and the worker streams to Deepgram, Claude and ElevenLabs. At the end it writes one report.

Figure 2 · one reply

How Giulia answered

Speech is written down in the deployment's one language, the turn detector decides the person is done, Claude replies (calling tools when needed), and the voice speaks.

Already solid

  • A supervised voice worker: restarts on a crash, moves to new code without dropping calls.
  • One call controller: every way a call can end goes through one path.
  • A timing report for every call, readable on /calls.
  • Fallbacks: two LLM routes, ElevenLabs falling back to Deepgram.

Missing

  • One language per deployment; no switch mid-call.
  • Giulia knew a first name and nothing else about the customer.
  • No traces: after hang-up only the report and the logs remained.
  • No grading, no simulated calls, no automated tests.

Shape

  • 12 agent tools, prompt v2.
  • Pages: Talk (emoji labels) and /calls.
  • Phone path (dialer, SIP, Postgres, post-call to HubSpot) written, not live.
