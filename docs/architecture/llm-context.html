What Giulia's LLM reads

Everything the model sees when it writes Giulia's next line: the prompt files and what fills them in, the tools, and the conversation so far. Paths are under backend/ai_sdr/.

Where the context comes from

Every request has three parts. The system prompt is rendered once per call from the prompt files, a few call facts and the customer card. The 14 tool definitions ride along unchanged. The chat history grows as the call goes on.

Figure 2 · one request

What one request carries

The first request of an Italian call, counted by the model's own tokenizer: 11.0k tokens before any history. The rules dominate; the part about this caller and today (demo card) is 3%.

Figure 3 · over a call

How the history grows

What gets appended, and when, in a short call with one calendar lookup. Each request sends the system prompt and the tools again, with the whole history.

Measured

  • System prompt: 8.7k tokens in Italian (26.3k characters), 6.6k in English (25.3k).
  • 14 tool definitions: 2.3k tokens, the same in both languages (written in English).
  • First request of a call: 11.1k tokens in Italian, 9.0k in English. The history then adds about 0.5k over a short call.
  • Local test calls: 9 requests for 4 replies (early replies, tool steps), 101k tokens in, 249 out, 0 cached.

Worth a look

  • No prompt caching: the LiteLLM route sends no cache breakpoints, so the same 11k-token prefix is processed again on every request.
  • Tool results carry instructions ("confirm like this: …"), so they act as a second prompt.
  • get_available_slots tells her to summarise ranges of times; the grader's booking check calls that vague.
  • Filler, are-you-there, sorry-repeat and closing lines enter the history as if she had chosen them.
  • record_qualification and schedule_callback errors answer in Italian even on English calls.

Not in the context

  • Audio and tone: only the transcript of what was heard.
  • Customer numbers: the card turns value and credits into words.
  • Pronunciation fixes, applied after the model, before the voice.
  • Prompt-file comments, timings, the picked voice, Langfuse grades.
  • One-off nudges (after a switch, a minute before the time limit) last for one reply.
